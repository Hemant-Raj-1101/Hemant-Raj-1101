## `module hemant_raj`

```verilog
module hemant_raj (
    input  wire       clk,
    input  wire       coffee,
    input  wire       curiosity,
    output reg  [7:0] skills,
    output wire       ready_for_vlsi
);
    // learning happens on every rising edge
    always @(posedge clk) begin
        if (coffee & curiosity)
            skills <= skills + 1;
    end

    assign ready_for_vlsi = (skills == 8'hFF);   // still loading... 🔍
endmodule
```
